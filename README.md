# Static Website Project

This is a simple static website starter project built with HTML, CSS, and JavaScript.

## Structure

- `index.html` - main page
- `assets/css/style.css` - site styling
- `assets/js/script.js` - small front-end behavior

## Run locally

From the project folder, start a local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customize

Update the text in `index.html` and the design in `assets/css/style.css` to match your brand.
